## Shared completion evidence

Every package needs a current-source reference, a model anchor, an approach view and a second view. Geometry packages additionally need matching browser/native exports, walking clearance and ball-contact checks. If a course surface moves, validate the affected native solution before integration. Shared layout, scene assembly and asset-manifest edits have one integration owner.

Reference images stay out of Git and out of the shipped texture pack. Create original geometry/artwork. Use the versioned asset-pack workflow in [ASSETS.md](ASSETS.md); do not commit Blender files or GLBs as part of ordinary source changes. Keep only the current pre-launch scene and courses.

Research gaps must remain explicit: the public maps are schematic; some photographed dates are unknown; a branded store does not imply surveyed shelf placement. A package is complete when its listed views and runtime checks pass, not when an object with the right name exists.
